# Eşref Kurt

**AI Engineer / Data Scientist** · Samsun, Türkiye

I train models on tables, images, and text, and I build RAG systems that answer from retrieved documents. I check the result and put the model in a small app. The repositories below are grouped practice projects and finished Kaggle exercises, not a dump of course files.

## What I work on

- Classical machine learning: regression, classification, clustering, time series
- Computer vision and NLP
- RAG: embed a catalog, retrieve the closest rows, and have a chat model answer only from those rows
- Recommendation systems and small AI agents
- Shipping a trained model with Streamlit
